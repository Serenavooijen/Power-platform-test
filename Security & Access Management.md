# Security & Access Management

> **Warning:** We are in the middle of developing the Security Access Best Practices, therefore this page has limited content.

- **Role-based access control (RBAC):** Use security roles and Microsoft Entra ID (Azure AD) groups.
- **Data loss prevention (DLP) policies:** Define what connectors can and cannot be used together.
- **Conditional Access:** Enforce security conditions for access (e.g., MFA).
- **Tenant isolation:** Prevent sharing of apps/flows outside the organization if needed.
