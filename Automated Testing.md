# Automated Testing

For automated testing we have several best practices and standards which are explained in this article.

## Purpose of this asset

To provide relevant tips and information for implementing automated testing for Model Driven Apps and Dynamics 365 CE in a structured way. It also highlights why we choose this method and contains starter projects and pipelines to use in a project.

## Target audience

This asset is meant primarily for the team involved in implementing (automated) testing, but is also relevant for the teams implementing or maintaining Model Driven Apps in general.
