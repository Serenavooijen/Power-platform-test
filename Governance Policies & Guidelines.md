# Governance Policies & Guidelines

To start with the Power Platform in a productive and secure way, each Power Platform requires a basic setup.

## Dynamics 365

This also applies to any Dynamics 365 solution which uses the Power Platform.

## Landing zone

The [landing zone](https://docs.hso.com/PowerPlatform/Governance/PoliciesGuidelines/landingzone.html) is the first stage in Power Platform Governance setup. It covers the Power Platform Setup, specifically the following aspects:

- Environment strategy (and creation)
- Azure AD configuration
- Power Platform Tenant settings
- Basic data loss prevention (DLP) policies
- Solution strategy (and creation)
- Deployment strategy (and setup)

### Power Platform Enterprise Management Workshop

This topic covers the technical setup of the Landing Zone.

In addition to this technical setup, there is a landing zone defined within the Power Platform Enterprise Management Workshop, which is part of the Cloud Assessment. This workshop also focuses on establishing governance from an organizational point of view. More information on this workshop can be found on the [Cloud Application Platform SharePoint site](https://hso1com.sharepoint.com/sites/HSOGlobalSLAP/Gedeelde%20documenten/Forms/AllItems.aspx?RootFolder=%2Fsites%2FHSOGlobalSLAP%2FGedeelde%20documenten%2FGeneral%2FOffer%20Book%2FCloud%20Assessment&FolderCTID=0x012000EE5347481EFAC74BB4EC66B1AC89103F).
