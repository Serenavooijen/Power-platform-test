# Monitoring

In order to do proper monitoring and troubleshooting of cloud flows, plug-ins and performance, you need to setup a [connection from Dataverse to Application Insights](https://learn.microsoft.com/en-us/power-platform/admin/overview-integration-application-insights). This should be done during the setup of the landing zone. It requires the Azure part of cloud foundation to be done.

## HSO Monitoring solution

Managed Services offers [a monitoring solution](https://docs.hso.com/Monitoring/) to help you with monitoring.

## Measuring performance

This can be done by querying Application Insights as described in the [Microsoft documentation](https://learn.microsoft.com/en-us/power-platform/admin/telemetry-events-model-driven-apps).

Next to that, some examples to measure performance and usage of model driven apps can be found [here](https://docs.hso.com/PowerPlatform/Apps/ModelDrivenApps/performance-usage.html).

## Troubleshooting

More information regarding troubleshooting can be found in the respective areas for [plugins](https://docs.hso.com/PowerPlatform/Development/Plugin/troubleshooting-plugins.html) and [cloud flows](https://docs.hso.com/PowerPlatform/PowerAutomate/troubleshooting.html).
